Tài liệu thiết kế & đặc tả

🐭 Mini game Đập Chuột

Bộ tài liệu mô tả tổng quan, chức năng, màn hình, quy tắc/dữ liệu và kế hoạch kiểm thử cho mini game đập chuột chạy trên trình duyệt. Tài liệu này mới chỉ đặc tả yêu cầu — chưa có code game.

1

Tổng quan

Mục tiêu, phạm vi, ngoài phạm vi và các quyết định thiết kế đã chốt.

 2

Chức năng

Luật chơi, cách tính điểm, cách điều khiển (chuột/chạm/bàn phím), điểm cao nhất.

 3

Màn hình

Mô tả và minh hoạ 3 màn hình: bắt đầu, chơi, kết thúc.

 4

Quy tắc & dữ liệu

Máy trạng thái, hằng số thời gian, quy tắc ngẫu nhiên, mô hình dữ liệu lưu trữ.

 5

Kế hoạch test

Bảng test case đối chiếu với tiêu chí hoàn thành trong YEU-CAU.md.
Nguồn yêu cầu gốc: YEU-CAU.md. Giao diện tài liệu dùng chung design token tại design/tokens.css. Giai đoạn này chưa viết code game — chỉ hoàn thiện đặc tả.
